# 无人机监管与反制推演系统 (Unity3D)

一个可直接运行的无人机监管/反制战术推演 Demo:黑飞无人机波次来袭,玩家运营"探测—警告—干扰—捕获—摧毁"多层处置体系,守住核心设施。

## 运行方式(零手工配置)

1. 用 **Unity 2020.3 LTS 或更高版本**(2021/2022/6000 均可)新建一个 3D 工程(模板选 "3D")。
2. 把本目录下的 `Assets` 文件夹整体拷入工程的 `Assets` 内。
3. 打开 Unity,等脚本编译完成(无报错)。
4. 新建一个空场景(`File → New Scene → Basic (Built-in RP)`),在 Hierarchy 里 `Create Empty` 一个空物体,命名为 `Boot`,把 `Assets/Scripts/MainBoot.cs` 拖到它上面。
5. 删除场景自带的 **Main Camera**(脚本会自己创建相机)。
6. 按 **Play** —— 整个推演环境(地面、分区圈、设施、雷达、反制单元、无人机生成)全部由代码自动搭建。

> 想更省事:场景里只留一个挂了 `MainBoot` 的空物体即可,其他什么都不用放。

## 玩法与操作

| 操作 | 功能 |
|---|---|
| 鼠标左键点击无人机 | 锁定目标 |
| 数字键 `1` | 对锁定目标实施 **电磁干扰**(迫降,约80%成功率) |
| 数字键 `2` | 对锁定目标发射 **捕获网**(必中捕获) |
| 数字键 `3` | 对锁定目标发射 **激光**(硬摧毁,误击合规机扣分) |
| `Tab` | 切换 **自动防御** 开/关 |
| `WASD` | 平移视角 |
| 按住鼠标右键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| `F` | 视角回到核心设施 |

## 推演规则

- **三类目标**:侦察机(蓝,多数合规)、攻击机(红,多数黑飞)、蜂群机(黄,全黑飞)。
- **三圈防御**:红色核心禁飞区(60m)、橙色预警区(120m)、蓝色警戒圈(200m),雷达覆盖420m。
- **处置手段**(模拟真实监管流程):
  - **RemoteID 警告**:合规无人机收到警告会调头离场(+60分,绿色尾迹);
  - **电磁干扰**:链路失锁强制迫降(+80分,黄色尾迹);
  - **捕获网**:物理捕获取证(+100分);
  - **激光**:硬摧毁(+70分);但若目标是合规无人机则 **误击违规 -50分**。
- **突破判定**:目标进入核心禁飞区即引爆,设施完整度 -10%、-150分;完整度归零则推演失败。
- 每 60 秒波次+1,来袭强度递增;界面右侧滚动显示事件日志,左下角是实时空情目标列表。

## 脚本结构

```
Assets/Scripts/
├── MainBoot.cs        场景自举:纯代码搭建全部环境(核心入口)
├── SimConfig.cs       参数常量 / 全局状态 / 计分 / 事件日志
├── Spawner.cs         波次生成器
├── EnemyDrone.cs      目标无人机AI(接近/调头/迫降/坠毁/被捕获)
├── DefenderUnits.cs   雷达站 / 反制单元(干扰·捕获网·激光)
├── Effects.cs         特效(爆炸/干扰波束/捕获网/激光)
├── SimUI.cs           IMGUI界面(状态栏/事件日志/目标列表/点选)
└── RTSCamera.cs       RTS风格相机控制
```

全部使用 Unity 内置管线 + IMGUI,无任何外部依赖,无需导入资源包。
